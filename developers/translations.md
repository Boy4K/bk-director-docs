# Translations

The language is chosen in the [Settings panel](../getting-started/settings.md): **English** or **Italiano**. It applies to every player immediately, no restart.

| File | What |
| --- | --- |
| `html/i18n.js` | the panel texts |
| `shared/defaults.lua` (`BK.EN`) | in-game messages, animation, filter and shake names |

Italian is the base language. To change an English text, edit its value in those two files.
