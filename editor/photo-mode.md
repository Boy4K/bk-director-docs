# Photo mode

Press **Photos** in the top bar, then **Enter photo mode**.

| Key | What |
| --- | --- |
| **Left click / Space** | take the photo |
| **Right click** | leave photo mode |
| **WASD, wheel, R/F** | move, zoom, roll |

A rule-of-thirds grid helps framing; it doesn't appear in the photo. Photos taken in the session show up in the strip at the bottom and in the **Photos** gallery.

## Send to Discord

If an admin sets a Discord webhook in the [Settings panel](../getting-started/settings.md), every photo is also sent there.

{% hint style="warning" %}
Photo mode needs the `screenshot-basic` resource.
{% endhint %}
