# Scene

The **Scene** tab holds the settings of the whole project.

<figure><img src="https://raw.githubusercontent.com/Boy4K/bk-director-docs/main/assets/scene.jpg" alt="The Scene tab"><figcaption><p>The Scene tab</p></figcaption></figure>

| Setting | What it does |
| --- | --- |
| **Duration** | length of the project in seconds (up to the server limit) |
| **Weather** | weather for the whole clip |
| **Hour / Minutes** | time of day, frozen for the whole clip |
| **Letterbox** | Cinemascope 2.39:1, Univisium 2:1, Cinema 1.85:1 or Vintage 4:3 bars |
| **Film grain** | grain over the whole clip |
| **Vignette** | dark corners over the whole clip |
| **Hide HUD and minimap** | clean screen while editing |
| **Hide my character** | your ped disappears from the shot |
| **Next keyframe distance** | how many seconds later **K** places a new keyframe when the playhead is already on one |
| **Bring camera to me** | brings the camera back to your character |

{% hint style="info" %}
Weather and time only change for you. With the private scene on, nobody else sees you editing.
{% endhint %}
