# Projects

| Action | How |
| --- | --- |
| Save | **Save** or **Ctrl S** |
| Open, delete | **Projects** in the top bar |
| New project | **Projects → New** |
| Rename | click the name next to the logo |

Projects are saved on the server per player (license), up to the limit set in the [Settings panel](../getting-started/settings.md) (15 by default). Takes are saved with the project: open it tomorrow and everything is there.

**Ctrl Z / Ctrl Y** undo and redo any change in the editor.
