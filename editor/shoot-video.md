# Shoot the video

<figure><img src="https://raw.githubusercontent.com/Boy4K/bk-director-docs/main/assets/shoot-video.jpg" alt="Shoot video"><figcaption><p>Shoot video</p></figcaption></figure>

**Shoot video** hides the interface and plays the project on a clean screen, with camera, effects and texts. Record the screen with **OBS**, **ShadowPlay** or the Windows Game Bar.

| Option | What it does |
| --- | --- |
| **From start** | plays the whole project |
| **From playhead** | starts where the playhead is |
| **3 second countdown** | time to start recording |

Press **Backspace** to stop.

{% hint style="success" %}
Record at your monitor's resolution with OBS "Game capture". Hide OBS's own overlay so nothing ends up in the clip.
{% endhint %}
