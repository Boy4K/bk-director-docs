# Commands and controls

## Commands

| Command | Who | What |
| --- | --- | --- |
| `/director` | everyone | opens the editor (the name can be changed in the settings) |
| `/director_debug` | everyone | shows the camera debug HUD (FOV and position) |

An admin can also set a default key to open the editor (for example `F10`). Players can change it in **Settings → Key Bindings → FiveM**.

## In the editor

| Key | What |
| --- | --- |
| **Right click** | fly the camera; click again to stop |
| **Space** | play / pause |
| **K** | add a camera keyframe |
| **← →** | one frame (Shift: one second) |
| **Delete** | delete the selection |
| **Ctrl Z / Ctrl Y** | undo / redo |
| **Ctrl D** | duplicate |
| **Ctrl S** | save |
| **H** | hide the interface |

## Flying the camera

| Key | What |
| --- | --- |
| **WASD** | move |
| **Q / E** | down / up |
| **Shift / Ctrl** | fast / slow |
| **Mouse wheel** | zoom (20–100) |
| **Z** | normal zoom (50) |
| **R / F** | roll |
| **H** | reset roll |
| **Left click, right click, Esc, Enter** | stop flying |

## While recording

| Key | What |
| --- | --- |
| **X** | stop the take |
| **Backspace** | stop the video while shooting |

## Who can open it

Every player. You can block it when the player is dead or cuffed, and set a cooldown, from the [Settings panel](settings.md).
